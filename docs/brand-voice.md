# MEASURE OS Brand Voice

OSTRA ブランドの文章基準。Webサイト・営業資料・採用資料・会社紹介・社内文書のすべてにおいて、このドキュメントを参照する。

---

## Brand Purpose

**読了後に、読者の中へ「観測」という世界の見方が残ること。**

製品を売らない。会社を売らない。  
制御の前に、まず観測する——その認識が、読者の現場と組織の中に残ることを目的とする。

ブランドサイトは、思想を体験し、その思想が現場に実装され、最後にその思想を持ち続ける主体として OSTRA にたどり着く一冊の文書である。

---

## Brand Voice

**現場を見続ける、静かな構造思考者。**

- 売らない。説得しない。問いを置く。
- 正しさより、見方の一貫性を語る。
- 主語は製品でも会社でもなく、**観測**である。
- 読者の違和感を知っている。背中から構造を示す。
- 熱量より論理。断言より余韻。

---

## Tone

| 場面 | トーン |
|---|---|
| Hero | 短い断定。説明しない |
| 見出し | 体言止め、または一句の断言 |
| 本文 | だ／である調。論証を重ねる |
| 余韻 | 問い、または認識の変化で終える |
| CTA | 短く。「〜へ」。売り込まない |

**文章の基本構造**

```
断言 → 論証 → 余韻
```

温度感は低く、静か。Apple・Stripe・Linear のような洗練された SaaS 口調を真似しない。

---

## Writing Rules

### 語尾

- 本文：**だ／である**調を基本
- Hero・見出し：体言止め、または「。」で断定
- Contact 等の最小行のみ、読みやすさのために例外可
- 避ける：ですます調（本文）、〜してください、〜しましょう

### 句読点

- **「。」** — 1文1義。断言の区切り
- **「、」** — 呼吸。3連続以上は文を分割
- **「——」** — 列挙・因果。ハイフン `-` ではなく em dash
- **「？」** — ブランド問い「観測されているか？」など、意図的な問いのみ
- **「！」** — 不使用

### 改行

- Hero・自分事：1フレーズ1行
- 本文段落：2〜3文まで
- 同文の言い換えを連続させない

### 漢字とひらがな

- **観測**は常に漢字。ブランドの中心語として最優先
- 補助語（構造・事実・組織）も漢字で固定
- 接続・余韻はひらがな可：しかし、なくては、だけ
- カタカナ：製品固有名（OS、Package、Field 等）に限定

### 英語表記

| 種別 | 表記 |
|---|---|
| 思想 | **Observe Before Control**（略さない） |
| 世界の見方 | **Observe / Structure / Trace** |
| 製品 | **MEASURE OS** |
| 画面 | Field / Priority / Observe |
| 会社 | OSTRA / 株式会社 OSTRA |
| 下層 kicker | **和文優先**（原則 / 実装 / 証拠 / 思想） |
| ナビ | TOP / Principles / MEASURE OS / OSTRA |

**Observe と Observer**

- 世界の見方・思想文脈：**Observe**
- OSTRA 名称の O（Observer）を語源として説明する場合のみ **Observer** 可

### 専門用語

- 「第○条」— `/principles` と `/measure-os` のみ
- 「統治」— OBC 文脈では **制御** に統一
- 「OS 化」「DX」「効率化」— 不使用
- 「世界の見方」— TOP III の専用語。下層では「この見方」「見方」

### CTA

- 形式：**「〈テーマ〉へ」**（例：思想の実装へ）
- 製品名を CTA に並べない
- 1ページあたりの CTA は最小限

## Core Word

### 観測

**ブランドコアワードは、この一語のみ。**

観測とは、感覚を事実に変え、組織に残す行為である。  
気付きの先。制御の前。ブランド全体で最も残したい言葉。

- 見出し・本文・CTA・下層ページすべてにおいて、**観測**を中心に書く
- 同義の言い換え（可視化、把握、見える化）で置き換えない
- 読了後、読者の頭の中に「観測」が残ることを最終基準とする

---

## Supporting Words

コアワード **観測** を支える説明語。主語にしない。観測を説明するために使う。

| 語 | 役割 |
|---|---|
| **構造** | 個人を超えて再現できる形。「空気」の対義 |
| **事実** | 争点のない残り。気付きが観測を経て到達する先 |
| **組織** | 観測を保持する主体。個人の頭の中の対義 |

**関係**

```
気付き →（観測）→ 事実 →（構造）→ 組織に残る
```

そのほか、文脈に応じて使う語：  
痕跡、思想、現場、認識、境界、入口、残す、共有、問い、主体、実装、証拠、観測インフラ

---

## Never

ブランドとして**絶対にしないこと**。

### 言葉

- DX と言わない
- 革命と言わない
- 効率化と言わない
- 最適化と言わない
- ゲームチェンジと言わない
- ソリューションと言わない
- オールインワンと言わない
- 次世代と言わない
- イノベーションと言わない
- 業界初と言わない
- AI で解決と言わない

### 態度

- 売り込まない
- 煽らない
- 競合比較をしない
- 過度な約束をしない
- 数字だけで価値を語らない

### 文体・構成

- Apple / Stripe / Linear 風のコピーにしない
- SaaS 的 kicker（Implementation、Experience、Solution）を乱用しない
- 「ブランド体験」などメタ語で読者に語らない
- 機能一覧・料金・プラン比較ページにしない
- 短くするためだけに思想を削らない
